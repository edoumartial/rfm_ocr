# DecisioOCR & RFM OCR API

Application de reconnaissance optique de caractères (OCR) et de traitement de décisions administratives, composée d'un front-end Java et d'un back-end Python FastAPI.

## 🛠️ Prérequis et Environnement de Développement

Pour faire tourner ce projet localement, assure-toi d'avoir installé les versions et outils suivants :

* **Java Development Kit (JDK) :** Version 17 ou supérieure (recommandé pour le front-end `DecisioOCR`).
* **IDE Java :** Apache NetBeans (dernière version recommandée).
* **Python :** Version 3.10 ou supérieure (pour le back-end `rfm_ocr_api`).
* **Base de données :** PostgreSQL gérée via **pgAdmin 4**.
* **Test d'API :** Postman (pour valider les endpoints de l'API FastAPI).
